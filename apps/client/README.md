# Cliente Oriens

SPA em React e TypeScript com Vite. Use Node 22 e execute em `apps/client/`.

```sh
npm ci
npm run dev
```

Abra `http://localhost:5173`. O [setup do cliente](../../docs/guides/setup.md#cliente)
explica como conectar à API local ou de teste e executar lint, testes, build e
Playwright. Para iniciar API, PostgreSQL e Vite juntos, veja o
[caminho rápido na raiz](../../README.md#primeiros-passos).
